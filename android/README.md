# JobFinder Android

Android port of the climate job finder: the TUI's search → swipe → apply flow
as a phone app, plus a share target for job URLs.

## What it does

- **Profile search** — queries the same nine sources as the Python app
  (Arbeitnow, RemoteOK, Adzuna, Greenhouse, Lever, ClimateTechList, Climatebase,
  Jobs in Carbon, Remote Impact), filters titles against the target-role
  profile, checks liveness, fetches full descriptions (once — failures retry
  after a week), scores fit + startup-ness + climate relevance with Claude
  Haiku, and opens a swipe deck sorted pearls-first, then most-recent-first.
  A **pearl** (🦪, supermatch) is all three scores ≥ 4 with sum ≥ 13; pearls
  get a banner on the card and a rougher single-pass "drunk draft" cover
  letter instead of the two-pass polished one.
- **Location policy** (fixed, in `Profile.matchesLocations`): Switzerland
  hybrid/remote/on-site; Germany and the Netherlands remote-only; other
  remote-EU/worldwide roles pass; remote roles restricted to non-EU regions don't.
- **Swipe deck** — swipe right to like, left to pass (or the underlined words at
  the bottom), 5-second undo, expandable description/company info, `apply` jumps
  to generation. Decisions persist in `job_decisions.json` in app storage, so a
  job is only judged once.
- **Share target** — share a job URL from any browser/app to JobFinder: it
  fetches the posting, extracts company/role with Haiku, and can write a cover
  letter (with optional extra context), answer application questions, or
  estimate salary — generated by Claude Sonnet in Milo's cover-letter voice
  (two passes: a silent draft, then a self-critique rewrite that hunts AI
  tells, streamed), with copy/share buttons. Shared URLs are saved as jobs (source `shared`) and
  synced to the other devices.
- **Cross-device sync** (`data/Sync.kt`, optional) — mirrors jobs, swipe
  decisions, and fetched descriptions to Cloud Firestore (Firebase SDK: Auth
  email/password + Firestore, project config in `app/google-services.json`),
  shared with the laptop's CLI/TUI (`sync.py` in the repo root), so nothing is
  judged twice. Two-way merge on app start (summary line on the menu), instant
  pushes on swipe/undo/search/share. Fill `FIREBASE_EMAIL`/`FIREBASE_PASSWORD`
  in `Keys.kt` with the same values as the repo's `.env`; blank = sync off.
  The Firestore SDK's offline cache means swipes made offline sync later.
- **Description fetching** — done during search and cached (`job_descriptions.json`
  in app storage). Resolution order: local cache → sync DB (another device may
  have it) → direct fetch → `r.jina.ai` rendering proxy for bot-walled/JS-only
  pages → feed snippet.

## Building

Same toolchain as Eigenflow (Gradle 8.13, AGP 8.12, Kotlin 2.0, compileSdk 34).
System Java is too new for Gradle; use the Android Studio flatpak JBR:

```bash
export JAVA_HOME=/var/lib/flatpak/app/com.google.AndroidStudio/current/active/files/extra/jbr
./gradlew :app:assembleDebug
```

Or open `android/` in Android Studio and run — it uses its own bundled JBR.

## Installing to a phone

Works whether the phone is on USB or wireless debugging (`adb pair`/`adb connect`),
and skips any running emulator so it always targets the real device:

```bash
ADB=~/Android/Sdk/platform-tools/adb
$ADB -s "$($ADB devices | awk '$2=="device" && $1 !~ /^emulator-/ {print $1; exit}')" \
    install -r app/build/outputs/apk/debug/app-debug.apk
```

If nothing prints from the `awk` part, the phone isn't visible to adb yet — check
Settings > System > Developer options > USB debugging is on (and USB mode is
"File Transfer"/"PTP", not "Charging only"), or re-pair wireless debugging.

## Personal files (gitignored, required to build)

- `app/src/main/java/dev/milo/jobfinder/data/Keys.kt` — API keys, baked in on
  purpose (personal build). Copy `Keys.kt.example` and fill in.
- `app/google-services.json` — Firebase project config for the registered
  Android app (`dev.milo.jobfinder`). Regenerate with
  `npx -y firebase-tools@latest apps:sdkconfig ANDROID <APP_ID> --project dog-o-meter`.
- `app/src/main/assets/resume.txt` — plain-text resume. Regenerate from the
  repo root with:
  `uv run python -c "from resume_data import resume_as_text; print(resume_as_text())" > android/app/src/main/assets/resume.txt`
- `app/src/main/assets/styleguide.md` — copy of `Cover-letter styleguide.md`.
